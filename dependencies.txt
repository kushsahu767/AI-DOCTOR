Environment variables / API services
-------------------------------------
GROQ_API_KEY=<your Groq API key>
ELEVENLABS_API_KEY=<your ElevenLabs API key>
ELEVENLABS_VOICE_ID=<your ElevenLabs custom voice ID>
GROQ_MODEL=qwen/qwen3.8-27b

Notes
-----
- Store the environment variables in a local .env file.
- Never commit .env or real API key values to Git.
- GROQ_API_KEY is used for vision analysis and Whisper transcription.
- GROQ_MODEL selects the Groq chat model and defaults to qwen/qwen3.8-27b.
- ElevenLabs variables are used only for ElevenLabs text-to-speech.
- The current Gradio application uses gTTS for its default voice response.
